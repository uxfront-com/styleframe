# @styleframe/figma

Keeps your Styleframe design tokens and your Figma variables in sync. It holds the Styleframe Figma plugin and the converters behind it, between Styleframe variables, Figma variables and DTCG JSON. The `styleframe figma` commands and `styleframe dtcg import` use the same converters.

## Install

```bash
pnpm add -D @styleframe/figma
```

## Documentation

- [Figma plugin](https://www.styleframe.dev/docs/getting-started/integrations/figma-plugin): installing the plugin and moving variables between Figma and your code.
- [Using Styleframe with AI agents](https://www.styleframe.dev/docs/getting-started/tooling/agents): the commands an agent runs to check its work, and the mistakes that build without a warning.
